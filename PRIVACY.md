# CookieJab Privacy Policy

CookieJab is a Chrome extension that injects request headers and cookies into the sites that you choose.

## Data That CookieJab Stores

CookieJab stores the rules that you create. A rule contains a name, a URL match pattern, a header or cookie name, and a value. The value can be an authentication token or another secret that you type.

Rules are stored with `chrome.storage.local` on your device. They are not synchronized to other devices. They are not sent to the developer or to any third party.

## Data That CookieJab Sends

CookieJab sends the header values and cookie values that you configured to the sites that match your rules. It sends them only to those sites. It does not send any data to any other destination.

CookieJab has no analytics, no telemetry, no crash reporting, and no remote code.

## Data That The Developer Receives

The developer receives no data from CookieJab.
